        Paramètres

        Ces informations servent à l'IA pour personnaliser vos emails. Elle n'invente rien : plus votre profil est précis, meilleurs sont les emails.

        L'application utilise un serveur llama.cpp (llama-server) qui tourne sur votre machine. Exemple :
        llama-server -hf ggml-org/gemma-3-4b-it-GGUF --no-mmproj -c 8192 --port 8080

        Les emails partent de votre propre boîte, via SMTP. Avec Gmail : activez la validation en deux étapes puis créez un mot de passe d'application (myaccount.google.com/apppasswords).

        Documents proposés en pièce jointe dans chaque candidature (CV, lettre…). PDF conseillé, 10 Mo maximum.

          L'application peut chercher seule de nouvelles offres pendant qu'elle est ouverte, avec les critères de votre dernière recherche (mots-clés, lieu, sites). Les emails ne partent jamais sans vous : l'IA prépare seulement des brouillons, que vous relisez avant d'envoyer.
